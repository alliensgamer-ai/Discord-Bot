Quiero convertir este proyecto en la versión final del bot de ranking competitivo para Free Fire.

IMPORTANTE:

* Mantén intactos el token DISCORD_TOKEN y el sistema actual de conexión.
* Mantén PostgreSQL como base de datos persistente.
* No elimines datos existentes.
* Mantén TypeScript + discord.js.
* Todo debe quedar modular y preparado para futuras temporadas.
* El bot debe funcionar principalmente en el canal de Discord destinado al sistema de ranking.
* Los comandos slash deben poder ejecutarse aunque los usuarios no tengan permiso para enviar mensajes normales en ese canal.
* Las respuestas de consultas personales deben ser ephemeral/privadas cuando corresponda.
* No permitas que usuarios normales puedan modificar puntos.

==================================================
SISTEMA DE JUGADORES

Cada jugador debe tener:

* Discord user ID
* Nombre/usuario de Discord
* Puntos actuales
* Salas jugadas
* MVP
* Segundos lugares
* Terceros lugares
* Últimos lugares
* Compe jugadas
* Guerras jugadas
* VV2 jugadas
* Actividades realizadas
* Puntos obtenidos por actividad
* Fecha de última actividad

Debe existir un historial completo de cambios.

==================================================
PUNTOS DE SALA

Cada sala utiliza estas reglas:

* Participación normal: +2 puntos
* MVP: +10 puntos
* Segundo lugar: +5 puntos
* Tercer lugar: +3 puntos
* Último lugar: +2 puntos

IMPORTANTE:
Los puntos de posición REEMPLAZAN los +2 de participación.
NO se suman entre sí.

Ejemplo:
MVP = 10 puntos totales, NO 12.

==================================================
/sala

Crear un comando administrativo:

/sala

Debe permitir registrar una sala y sus participantes.

Debe permitir seleccionar:

* Participantes
* MVP
* Segundo
* Tercero
* Último
* Nota opcional

Validaciones:

* Un jugador no puede ocupar dos posiciones en la misma sala.
* MVP, segundo, tercero y último deben pertenecer a los participantes.
* No registrar dos veces la misma sala.
* Debe existir al menos un participante.
* La operación completa debe hacerse en una transacción.
* Si algo falla, no debe quedar ningún punto parcialmente registrado.

Al registrar:

* Crear la sala.
* Crear los resultados de cada jugador.
* Actualizar puntos.
* Actualizar estadísticas.
* Crear entradas en el historial.
* Mostrar un resumen de la sala.

El resumen debe mostrar cuánto recibió cada jugador.
